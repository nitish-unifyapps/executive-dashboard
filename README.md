# Executive Dashboard

A static executive intelligence dashboard prototype built with HTML and JavaScript.

## Pages

- Executive Intelligence
- Market Insights
- Product and Competitor Intel
- Strategic Priorities

## Vercel

Use the **Other** framework preset with no install or build command. The repository includes a root rewrite:

- Source: `/`
- Destination: `/Executive-Intelligence.dc.html`

All runtime scripts and required product images are committed with the site.
